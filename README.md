🌱 Crop Sense

Crop Sense is an IoT-based smart agriculture project that monitors soil moisture in real time using an ESP32 and soil moisture sensor.

🚀 Features

- Real-time soil moisture monitoring
- ESP32-based IoT system
- Wi-Fi data transmission
- Node.js and Express.js backend
- Responsive web dashboard

🛠️ Technologies Used

- ESP32
- Soil Moisture Sensor
- Arduino IDE
- Node.js
- Express.js
- HTML
- CSS
- JavaScript

🔄 Working

Soil Moisture Sensor → ESP32 → Wi-Fi → Node.js Backend → Web Dashboard

 📌 Project Status

Currently monitoring soil moisture using ESP32 and displaying the data on a web dashboard.
